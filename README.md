# Bresenham Line Rasterizer

Using this console program, you insert the start and the end point of an arbitrary line and get the pixel coordinates of the rasterized line.

The underlying concept is based on Bresenham's line rasterizaton algorithm.


# How To Run The Code

To run this program, having Visual Studio 2015 or newer installed is required. To run the program, do the following steps:

1. Download the repository
2. Open the file with .sln format
3. In Visual Studio, run the program
